## 主指标

| 指标 | 定义与报告 |
| --- | --- |
| HotpotQA EM / F1 | 公开评测脚本的答案规范化与 token F1；**只对派生子集**报告，不冒充 fullwiki |
| Supporting-fact recall | 找回 gold 支持位置的覆盖率；与引用准确性分开报告 |
| 中文 rubric score | 按预登记需求项与关键事实逐项；报告均值与类别分 |
| 引用支持率 G | 被引用原文实际支持的原子 claim–evidence 关系数 / 待判关系数 |
| 引用覆盖率 | 有充分原文支持的关键 claim 数 / 全部关键 claim 数 |
| 无依据结论率 | 关键结论中无足够支持的比例；遗漏关键需求另记 |
| 拒答 Precision / Recall | 对 gold 不可回答任务；无答案类单独报告 |
| 提前停止率 | gold 可回答但关键证据尚缺且策略 finish/abstain 的比例 |
| 冗余工具率 | 未新增可用来源/原文/覆盖的重复工具调用比例 |
| 总模型资源 | 全部节点输入/输出 Token（含失败、核验、修复） |
| 实际费用 | GPU / 教师 / 搜索 分开；代理 Token 价另列 |
| 延迟 | 排队、服务端、端到端；p50 / p95 |
| 执行可靠性 | 成功、超时、取消、工具失败、解析失败分别统计 |

## 质量分 Q

- **英文：** 标准 F1（派生子集）。  
- **中文可回答：** `Q = 0.5×gold关键事实覆盖 + 0.3×适用范围正确率 + 0.2×结果状态正确性`，各项 ∈ [0,1]。  
- **证据不足：** 正确报告不足且无伪造关键事实 → Q=1，否则 0。  
- **版本冲突：** rubric 须保留双方条件。  
- 发布选择时英/中等权汇总（S40）。

## G 与辅助检查

- G **不能**只依赖在线同一基座 Verifier。  
- 英文：gold 支持位置 + 独立 MiniCheck（`flan-t5-large`）辅助。  
- 中文：gold rubric + 教师辅助 + 盲审抽查；MiniCheck **不**自动迁移中文。  
- 无 claim 的任务：引用支持率记 **NA**，不记 100%；应回答却无内容 → 任务质量 0。

## 联合证据

必须多份资料共同支持的结论：支持判断对象是 claim 与其完整 evidence set；无关引用记冗余。
